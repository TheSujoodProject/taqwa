[![Build Status](https://img.shields.io/badge/build-passing-brightgreen?style=flat-square)](https://github.com/TheSujoodProject/taqwa/)

A modern, elegant web application crafted to deliver a seamless experience for exploring the Quran. Taqwa combines authentic arabic script, precise English translations, and intuitive features like random verse generation and audio playback.

## About

Taqwa offers a refined platform for engaging with Quranic verses. With a focus on usability and aesthetics, it provides high-quality Arabic typography, Sahih International translations, and a suite of features designed for accessibility across all devices.

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Git (optional, for cloning the repository)
- A code editor (recommended: Visual Studio Code)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/TheSujoodProject/taqwa.git
   ```
2. Navigate to the project directory:
   ```bash
   cd taqwa
   ```
3. Open `index.html` in a web browser or serve it using a local development server (e.g., VS Code Live Server).

### Usage
- Click **New Verse** to explore a random Quranic verse.
- Switch between dark and light themes using the toggle.
- Save verses to **Favorites** or review **Recent Verses** in their dedicated sections.
- Play recitations using the integrated audio player.
